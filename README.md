# 勤怠ボット

対象ワークスペース向け、本人専用のSlack勤怠Botです。

## 確定仕様

| コマンド | 動作 |
|---|---|
| `/start` | 作業開始 |
| `/break` | 休憩開始 |
| `/resume` | 作業再開 |
| `/end` | 終了して休憩を除いた実働を保存 |
| `/week` | 月曜始まりの今週の終了済み実働 |
| `/month` | 今月の終了済み実働 |

`/today` はありません。集計は日本時間の開始日へ全時間を計上します。23時から翌1時までなら前日の2時間、翌0時30分に開始なら翌日の勤務です。休憩・再開では所属日を変えません。作業中・休憩中の未終了勤務は集計に含めません。時間は内部ではミリ秒、Sheetsでは小数の分、Slack表示時だけ分単位で四捨五入します。

## 構成

Slack → Cloudflare Workers（署名・本人確認）→ Durable Object（保存・集計）→ Apps Script（署名・重複確認）→ Google Sheets

Cloudflareを記録の正本とし、Sheetsは自動反映先です。シートを手で編集してもSlack集計には反映されません。終了時はCloudflare保存後に応答し、Sheetsへの転記は別処理で行います。失敗した転記は最大1時間間隔で再試行します。本人以外には記録を変更させず、通常のチャンネルメッセージは読みません。Slackコマンドには本人だけが見える応答を返し、開始・休憩・再開・終了は 投稿先チャンネル へBotとして投稿します。勤務開始で新しい親投稿を作り、通知先ユーザー を親投稿だけでメンションします。以後の操作は同じスレッドに返信します。週・月の集計は公開投稿しません。

## 接続設定

Cloudflareの暗号化シークレット（値をGitやチャットに保存しないこと）：

- `SLACK_SIGNING_SECRET`：SlackアプリのSigning Secret
- `SLACK_BOT_TOKEN`：Work TrackerのBotトークン
- `GAS_URL`：Apps Scriptウェブアプリの `/exec` URL
- `GAS_SHARED_SECRET`：Apps Scriptと共有する署名用の鍵

`wrangler.jsonc` の通常設定：

- `ALLOWED_USER_ID`：`U00000001`（本人）
- `ALLOWED_TEAM_ID`：`T00000000`
- `POST_CHANNEL_ID`：`C00000000`
- `MENTION_USER_ID`：`U00000002`（通知先ユーザー）

Apps Scriptには `gas/Code.gs` と `gas/appsscript.json` を反映し、スクリプトプロパティに `GAS_SHARED_SECRET` を設定します。`setup()` は記録用シートを作成し `SPREADSHEET_ID` を保存します。既存シートを使う場合は先にそのIDを設定します。ウェブアプリは本人権限で実行し、Workerから呼べるよう公開します。受信した本文の署名を検証するため、公開URLだけでは記録できません。

Google権限の認可とSlackの `commands` 権限によるインストールを完了してから、実機で開始→休憩→再開→終了を確認してください。テスト勤務は実データと混同しないように扱います。

## 運用上の注意

Slack再送はリクエストID、Sheets転記は勤務IDで重複排除します。外部障害時にも終了記録はCloudflareに残ります。Sheetsへの反映待ちは週/月集計の応答に表示されます。Cloudflareの保存状態やDurable Objectの削除は勤務記録の消失につながるため、通常のデプロイでは削除しないでください。履歴が大きくなった場合は集計の期間別インデックス化が必要です。

## スレッド投稿

投稿先IDは `C00000000`。追加設定は `SLACK_BOT_TOKEN`、`MENTION_USER_ID`（通知先ユーザーの確認済みID）です。Botは対象チャンネルに追加済みです。投稿権限は `chat:write` のみを追加し、メッセージ閲覧権限は要求しません。

記録の保存と投稿待ちの保存を同じトランザクションで行います。親投稿のSlack時刻を保存してから返信を送ります。投稿結果がネットワーク切断などで不明になった場合は `uncertain` 状態で止め、重複メンションを避けます。その場合は管理者が実際のスレッドを確認して投稿待ちを復旧する必要があります。コマンド応答には投稿待ちがあることを表示します。

Google記録先：https://docs.google.com/spreadsheets/d/<SPREADSHEET_ID>/edit

## 月別給与（2026-09-28）

時給（HOURLY_RATE）。終了済みの実働を開始日の月で合計し、月合計に対して1円未満を四捨五入。計算途中では時間を丸めません。`/month` は給与対象実働を時分秒で表示し、時給・今月の合計給与も返します。`/week` は従来の実働集計です。

動作確認2件の記録IDは `src/payroll.js` と `gas/Payroll.gs` で給与対象から除外します。原記録を削除せず、給与集計の対象のみを変えます（シートからすでに除かれている場合も除外条件は保持）。

- 「月別給与」: 全月の給与対象実働・時給・合計給与の一覧。
- 「YYYY-MM」: 1日1行の「日付・休憩合計・実働合計・給与（円）」。上部の集計欄と末尾合計は設けません。日別給与は小数2桁表示で、計算値は丸めず保持し、月別給与で月合計を四捨五入します。
- 「勤怠」: 非表示のGAS転記先。開始・終了を含む原記録を保持し、月別シートはここを参照する数式です。

GAS `doPost` が転記時に当該月のシートを自動作成。過去のシートは維持し、数式により追加記録へ追従します。`setupPayroll()` で既存記録の月を初期作成できます。ローカルの `gas/Code.gs` と `gas/Payroll.gs` を反映してください（現在のブラウザー版は同内容を1ファイルにまとめて配置）。GAS公開バージョン3（日別表示）、既存URLを維持。
